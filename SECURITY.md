# Security

This is an unpublished, pre-release package. No published version is currently
covered by a security-support commitment.

Labels and series names are inserted as text, not HTML. Callers should supply
trusted options and validate data from their own sources. SVG paint values are
passed to the browser as supplied. The library does not load scripts or fonts.

A private reporting channel is not yet configured. Before the first npm release,
enable GitHub's private vulnerability reporting and document its URL here.
Do not publish exploitable details or sensitive information in a public issue.
The release checklist includes this setup.
